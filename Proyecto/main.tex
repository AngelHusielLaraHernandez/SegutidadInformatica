\section{Definición Empresarial}
% =========================================================

\textbf{Aetheria FinTech \& AI Solutions S.A. de C.V.} es una empresa mexicana dedicada al desarrollo de herramientas de inteligencia artificial para el sector financiero. Su servicio principal consiste en un asistente automatizado y un motor de evaluación crediticia que ayuda a financieras y cajas de ahorro a responder dudas de clientes y calificar solicitudes de préstamo en pocos segundos.

En la Tabla~\ref{tab:definicion-empresarial} se describen los datos generales de la organización, su giro, sus objetivos y los servicios que ofrece.

\textbf{4. Aetheria Custom-Train:} Servicio de ajuste y entrenamiento del modelo utilizando el dataset de la empresa sobre la infraestructura física de servidores GPU. \\

\section{Identificación de Activos de Tecnología e Información}
% =========================================================

El inventario tecnológico de la empresa abarca tanto la infraestructura que da soporte al modelo de inteligencia artificial (la base de datos del modelo, el servidor que la aloja, el modelo mismo junto con el archivo de Python que es el bot, el dataset de entrenamiento y los servidores físicos de cómputo GPU) como los equipos de red y servidores de aplicación que permiten dar servicio hacia internet (el servidor frontal Linux webserver y el servidor interno Windows codeserver).

% ---------------------------------------------------------
\subsection{Diagrama de Red de la Organización}
% ---------------------------------------------------------

La red de la empresa está dividida en cuatro segmentos (Figura~\ref{fig:red-aetheria}):
\begin{enumerate}[noitemsep,topsep=2pt]
    \item \textbf{Zona Externa y Perímetro:} Punto de entrada para los clientes desde internet mediante conexiones HTTPS a través de Cloudflare y el firewall perimetral.
    \item \textbf{Zona Desmilitarizada (DMZ, subred 192.168.177.0/24):} Contiene el servidor Linux frontal \textbf{webserver} con IP 192.168.177.129 (interfaz eth0), donde corren \textbf{Apache 2.4.10} en el puerto 80/tcp y \textbf{OpenSSH 6.7p1} en el puerto 13337/tcp. Este equipo tiene una segunda tarjeta de red (eth1 con IP 10.0.0.78) conectada hacia la red interna.
    \item \textbf{Red Interna de Producción (subred 10.0.0.0/24):} Segmento privado donde se ubica el servidor \textbf{codeserver} (10.0.0.201) con \textbf{Windows Server 2012 R2 Standard} (puertos RDP 3389/tcp y WinRM 5985/tcp). En este servidor se ejecuta en producción \textbf{el archivo de Python que es el bot}.
    \item \textbf{Zona de Datos y Entrenamiento IA (rango 10.0.0.210 a 10.0.0.230):} Red interna donde se encuentran el \textbf{Servidor de Base de Datos} (10.0.0.210), la \textbf{Base de Datos del Modelo de IA}, el \textbf{Dataset de Entrenamiento} (10.0.0.220) y la \textbf{Infraestructura Física GPU} (10.0.0.230).
\end{enumerate}

\subsection{Cálculo del Nivel de Riesgo}
% ---------------------------------------------------------

El nivel de riesgo de cada escenario se obtiene multiplicando la frecuencia anual ($F$) por el promedio de los cuatro rubros de impacto ($I_{\text{prom}}$):

\begin{enumerate}[leftmargin=1.5cm]
    \item \textbf{Escenario 1 (RK-001: Intrusión en webserver, escalación a root y pivoteo hacia codeserver):}
    \begin{itemize}[noitemsep,topsep=2pt]
        \item \textbf{Frecuencia Anual ($F_1$):} $F_1 = 5.0$ ($100 < N$ eventos anuales de escaneo y fuerza bruta sobre el servidor expuesto en la DMZ).
        \item \textbf{Calificación General del Impacto ($I_{\text{prom},1}$):}
        \[
            I_{\text{prom},1} = \frac{I_{\text{ganancia}} + I_{\text{costo\_respuesta}} + I_{\text{reputacional}} + I_{\text{multas}}}{4} = \frac{4.0 + 2.0 + 4.0 + 3.0}{4} = \frac{13.0}{4} = 3.25
        \]
        \item \textbf{Calificación General del Nivel de Riesgo ($R_1$):}
        \[
            R_1 = F_1 \times I_{\text{prom},1} = 5.0 \times 3.25 = 16.25 \quad \Longrightarrow \quad \textbf{Nivel de Riesgo: CRÍTICO}
        \]
    \end{itemize}

    \item \textbf{Escenario 2 (RK-002: ShadowAI y exposición del archivo de Python que es el bot, dataset y BD):}
    \begin{itemize}[noitemsep,topsep=2pt]
        \item \textbf{Frecuencia Anual ($F_2$):} $F_2 = 4.0$ ($10 < N \leq 100$ eventos anuales de uso no autorizado de plataformas externas de IA).
        \item \textbf{Calificación General del Impacto ($I_{\text{prom},2}$):}
        \[
            I_{\text{prom},2} = \frac{I_{\text{ganancia}} + I_{\text{costo\_respuesta}} + I_{\text{reputacional}} + I_{\text{multas}}}{4} = \frac{4.0 + 1.0 + 3.0 + 3.0}{4} = \frac{11.0}{4} = 2.75
        \]
        \item \textbf{Calificación General del Nivel de Riesgo ($R_2$):}
        \[
            R_2 = F_2 \times I_{\text{prom},2} = 4.0 \times 2.75 = 11.00 \quad \Longrightarrow \quad \textbf{Nivel de Riesgo: ALTO}
        \]
    \end{itemize}
\end{enumerate}
