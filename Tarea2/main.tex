\subsubsection{Vim, git, nmap, hydra:}

\textbf{Vim} (editor de texto avanzado en terminal), \textbf{Git} (sistema de control de versiones), \textbf{Nmap} (escáner de red para descubrimiento de puertos y servicios) e \textbf{Hydra} (herramienta para realizar ataques de fuerza bruta a servicios de inicio de sesión).

\textbf{Comando:}
\begin{lstlisting}[language=bash]
sudo apt install -y vim git nmap hydra
\end{lstlisting}

\begin{itemize}
    \item \texttt{apt install}: Invoca al gestor de paquetes de Debian para instalar software.
    \item \texttt{-y}: Bandera que responde a las confirmaciones de espacio en disco, permitiendo una instalación fluida.
    \item \texttt{vim git nmap hydra}: Los nombres exactos de los paquetes a descargar e instalar.
\end{itemize}

\subsubsection{subfinder:}

\textbf{Subfinder} es una herramienta rápida de descubrimiento pasivo de subdominios. De hecho 
antes de la instlacion, fue necesario agregar la ruta de binarios de Go a las variables de entorno del sistema operativo para poder ejecutar las herramientas sin escribir su ruta completa.

\textbf{Comandos:}
\begin{lstlisting}[language=bash]
echo 'export PATH=$PATH:$HOME/go/bin' >> ~/.bashrc
source ~/.bashrc
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
\end{lstlisting}

\begin{itemize}
    \item \texttt{echo ... >> \textasciitilde{}/.bashrc}: Imprime la ruta de Go y la concatena (\texttt{>>}) al final del archivo oculto de configuración de la terminal del usuario.
    \item \texttt{source \textasciitilde{}/.bashrc}: Recarga la configuración de la terminal inmediatamente.
    \item \texttt{go install}: Instruye al compilador de Go a descargar y ensamblar un programa.
    \item \texttt{-v}: Modo detallado (\textit{verbose}), muestra en la pantalla cada archivo que se está procesando.
    \item \texttt{@latest}: Asegura que se descargue la versión más reciente del repositorio de GitHub.
\end{itemize}

    \item \textbf{Agregue el usuario creado en el proceso de instalación al archivo de sudoers para asignar privilegios de administración y la capacidad de utilizar el comando sudo. ¿Cuál es la ruta donde se encuentra el archivo de sudoers?}

    El tamaño de la respuesta (carga útil por defecto en Linux) al enviar paquetes al servidor DNS 8.8.8.8 es de \textbf{64 bytes}.

    El comando principal y necesario para validar e indexar la lista de actualizaciones disponibles en los repositorios es \texttt{sudo apt update}. Posteriormente, para aplicar e instalar dichas actualizaciones en el sistema, se utiliza el comando \texttt{sudo apt upgrade}.

    Para cumplir con este paso, se creó el documento ejecutando \texttt{vim instalacion.txt}, se presionó la tecla \texttt{i} para entrar en el modo de inserción (\texttt{-- INSERT --}) y se redactó la descripción solicitada. 
    
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.8\textwidth]{image/Parte2/image17.png}
        \caption{Redacción del proceso de instalación dentro de Vim (Modo Inserción).}
    \end{figure}

    La secuencia de comandos exacta necesaria para salir del editor y guardar los cambios es la siguiente:
    \begin{enumerate}
        \item Presionar la tecla \textbf{\texttt{Esc}} (para abandonar el modo de inserción).
        \item Escribir los caracteres \textbf{\texttt{:wq}} (donde `w` indica \textit{write} y `q` indica \textit{quit}).
        \item Presionar la tecla \textbf{\texttt{Enter}}.
    \end{enumerate}
